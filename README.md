# 🐦 Incullano S.A.S.

Sitio web informativo oficial de **Incullano S.A.S.**, empresa ubicada en **Yopal, Casanare, Colombia**, dedicada a la crianza y comercialización de codornices y sus productos.

## 🌱 Sobre Incullano

Incullano S.A.S. trabaja en la crianza de codornices y comercialización de productos derivados, ofreciendo atención directa a nuestros clientes desde Yopal, Casanare.

### Nuestros productos

* 🥚 Huevos de codorniz
* 🐦 Codornices en pie con diferentes edades de crianza

La disponibilidad de los productos puede consultarse directamente a través de nuestros canales de contacto.

## 🌐 Sitio web

La página fue desarrollada como un sitio web informativo moderno, rápido y adaptable a diferentes dispositivos.

Entre sus características se encuentran:

* Diseño responsive para computadores, tablets y celulares
* Información sobre Incullano S.A.S.
* Catálogo informativo de productos
* Información sobre nuestra crianza
* Contacto directo mediante WhatsApp
* Botón flotante de WhatsApp
* Diseño basado en la identidad visual de Incullano
* Optimización para despliegue en Vercel

## 🛠️ Tecnologías utilizadas

El proyecto fue desarrollado utilizando:

* React
* Vite
* Tailwind CSS
* JavaScript
* HTML5
* Vercel para despliegue

## 🚀 Ejecutar el proyecto localmente

Primero instala las dependencias:

```bash
npm install
```

Luego inicia el servidor de desarrollo:

```bash
npm run dev
```

Vite mostrará una dirección local, normalmente:

```text
http://localhost:5173
```

## 📦 Crear versión de producción

Para compilar el proyecto:

```bash
npm run build
```

Los archivos optimizados serán generados dentro de:

```text
dist/
```

Para probar localmente la versión de producción:

```bash
npm run preview
```

## ☁️ Despliegue

El proyecto está preparado para desplegarse utilizando **Vercel**.

Configuración:

```text
Framework: Vite
Build Command: npm run build
Output Directory: dist
```

Al conectar el repositorio de GitHub con Vercel, los nuevos cambios enviados a la rama principal pueden desplegarse automáticamente.
